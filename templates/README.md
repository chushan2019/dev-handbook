# dev-handbook 手册写作模板

本目录存放手册/速查卡的写作模板，保证未来每份文档格式统一、结构一致。

## 完整手册模板骨架（供复制）

```
# {主题} 完全指南

## 五分钟速览（核心结论）
- 结论 1
- 结论 2

## 01 是什么（入门，先比喻后本质）

## 02 底层原理（进阶必读，揭示指针/模型等本质）

## 03 什么时候使用（场景 + 判断标准）

## 04 关键操作与方式对比

## 05 可视化图解（正常流程 + 异常后果）

## 06 命令速查表（危险命令标⚠）

## 07 常见坑与最佳实践
```

## 速查卡模板骨架（供复制）

```
# {主题} 速查卡

## 高频命令
| 命令 | 作用 | 风险 |
|---|---|---|
```

> 说明：本目录下仅放模板文件，不放手册正文。
